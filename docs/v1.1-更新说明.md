# 灵犀 v1.1 更新说明（p0-security-arch 分支）

> 主题：从"演示级原型"到"可上线的陪伴产品"。
> 六个提交、四个差异化方向全部落地，测试从 0 → 51 个。

## 一、安全与架构收敛 `2858869`

**问题**：API Key 通过 `NEXT_PUBLIC_` 前缀打进浏览器 bundle，任何访客可提取盗用；`output: "export"` 静态导出导致 API 路由从未部署，记忆摘要系统在生产环境静默失效。

**改动**：
- 所有 LLM 调用收敛到服务端 `/api/chat`，Key 只存在于服务端环境变量
- 移除静态导出，记忆摘要恢复工作
- 修复 Dockerfile（原构建必失败）：多阶段构建，Key 运行时注入
- 重复的回复解析逻辑合并为 `llm-parse.ts`，配套本仓库第一批单元测试

## 二、服务端调度 + Web Push `029b290`

**问题**："TA 会主动找你"只在页面开着时生效——关掉网页，核心卖点就不存在。

**改动**：
- 腾讯云 CloudBase 后端：云数据库四集合 + 六个 API 路由
- 云函数 `proactive-tick` 定时触发器（5 分钟一次）扫描到期消息，经 Web Push 推送到浏览器——**页面关着也能收到"TA 主动找你"**
- 匿名设备 ID + 客户端同步层；记忆与调度上云，换设备/清缓存不再丢失
- 降级契约：未配置后端时全部静默回落 localStorage，本地开发零配置

## 三、分层记忆 `97110c1`

**问题**：单层"退出摘要"记不住细节，也无法沉淀关系。记忆是陪伴产品的护城河。

**改动**：
- 三层记忆结构：**事实库**（关于你的稳定事实）/ **情节记忆**（每次聊天的日记条目）/ **关系里程碑**（第一次聊天、走心时刻、结局）
- `/api/summary` 原有的一次 LLM 调用同时提取全部三层，零额外成本
- 对话时注入裁剪版记忆块，带"昨天 / 1周前"相对时间标签
- TimelineView 新增 **"你们的故事"** 区块：TA 的人生时间线下面，是你们共同的时间线

## 四、诚实 AI + 危机干预 `be3843e`

**问题**：prompt 指示模型否认自己是 AI（合规风险），且对情绪危机没有任何接住机制。

**改动**：
- 角色被认真问起时坦然承认是 AI 伙伴，用人设语气说、说明关心是真的；选择页加"AI 虚拟角色"披露，对齐生成式 AI 标识要求
- 危机信号检测：命中自伤/轻生表达时，心理援助热线卡片（12356 / 400-161-9995）**立刻本地展示、不依赖 LLM**，同时向模型注入危机响应指令（认真对待、先陪伴、不说教）
- 真实大学名全部替换为虚构校名，消除仿冒风险
- 心情引擎误判修复："下午6点"不再被当正面信号、"特别"不再命中"别"、用户倾诉"我好累"时角色转入关切而非自己 emo

## 五、实时信息管道 `4b5f8f0` `fd37c41`

**问题**："信息型陪伴"是硬编码的假话题，prompt 还鼓励模型编造比分——被拆穿一次就毁掉信任。

**改动**：
- 真实数据源：足球比分接 football-data.org（已实测返回真实世界杯赛果），科技/游戏/新闻接公开 RSS（IT之家/机核/澎湃）
- 服务端注入、15 分钟缓存、4 秒超时，任何源挂掉静默回落内置话题池
- 队名/联赛名中文映射（"世界杯：墨西哥 2-3 英格兰"）
- prompt 新铁律：**只用提供的真实信息聊具体比分和数字，没有的坦然说"没看到"**——真朋友本来就不是什么都知道
