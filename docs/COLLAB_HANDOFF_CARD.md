# LifeScript Collaboration Handoff Card

面向 Knot / WorkBuddy / 同组协作者在比赛冲刺期交接当前工作区时使用的极简交接卡。

当 `npm run build` 与 `npm run lint` 已通过，但工作区已经存在较多未提交改动、又希望后续协作者快速接手而不误判风险时，优先使用这份文档。

---

## 1. 这份交接卡回答什么问题

它主要帮助下一位接手者快速判断：

1. 当前是否仍在正确基线分支上
2. 当前工作区是不是已经较脏
3. 这轮改动更适合继续补文档、做微优化，还是应该先暂停
4. 继续推进前最少需要确认什么
5. 应该如何用一句话对外说明当前版本状态

这份文档不替代详细设计文档，也不替代 `git diff`；它更像是“先把局面讲清楚”的交接速卡。

---

## 2. 适用场景

尤其适合以下情况：

- 比赛冲刺期，多轮自动迭代后工作区已经不够干净
- 需要把当前版本转交给另一位协作者继续推进
- 需要把当前状态同步给答辩准备、录屏准备或代码接手的人
- 需要快速说明“为什么这轮没有继续改核心业务代码”
- 需要在不展开长篇背景介绍的前提下完成一次安全交接

---

## 3. 交接前固定检查

先执行：

```bash
git status --short --branch
git branch --show-current
npm run build
npm run lint
```

如果准备提交、发起 PR 或做完整交接，还可补充：

```bash
npm run verify
```

---

## 4. 60 秒交接顺序

推荐按下面顺序口头或文字同步：

1. **当前分支**：是否仍在统一基线分支
2. **工作区状态**：是否已有较多未提交改动
3. **本轮验证**：`build` / `lint` 是否通过
4. **本轮动作**：这轮到底改了什么
5. **风险边界**：哪些地方这轮故意没碰
6. **接手建议**：下一步更适合继续做什么

---

## 5. 一句话交接模板

### A. 适合发给协作者

```text
当前仍在 feat/v12-unified-baseline，build 和 lint 已通过，但工作区已有较多未提交业务改动；这轮只做了低风险独立增强，没有继续扩大核心页面冲突面，下一步更适合继续补独立文档、演示辅助信息或明确无争议的微体验优化。
```

### B. 适合发给答辩/录屏协助者

```text
当前版本可作为 V12 演示基线使用，主链路可讲，工程验证通过；考虑到工作区已有较多在途修改，这轮优先交付了不影响现有业务改动的独立补强内容。
```

### C. 适合发给下一位代码接手者

```text
如果下一步需要碰核心业务逻辑，请先厘清当前未提交改动的归属与边界；如果只是继续稳步推进，优先选择低冲突的小增强或独立文档交付。
```

## 6. 文字版交接模板

可直接复制以下模板：

```markdown
## 交接摘要
- 当前分支：
- Git 状态概览：
- 本轮验证：`npm run build` / `npm run lint` / `npm run verify`
- 本轮目标：
- 本轮改动：
- 明确未触碰区域：
- 当前版本是否可演示：
- 下一步推荐方向：
- 暂不建议动作：
```

## 7. 什么情况下应该暂停，而不是继续交接后直接开改

出现以下任一情况时，建议先暂停并重新确认边界：

- 需要判断现有未提交改动该保留还是覆盖
- 需要在多个业务方案之间做取舍
- 准备修改主状态机、共享类型或恢复逻辑
- 预计会跨多个核心页面联动修改
- 当前交接人无法清楚说明这轮改动到底解决了什么

---

## 8. 接手后的推荐动作优先级

### 第一优先级：继续低冲突推进

适合继续：

- 独立文档补充
- 演示 / 答辩 / 录屏辅助材料
- 明确无争议的文案优化
- 无障碍补充
- 基于现有状态字段的小展示增强

### 第二优先级：做一次完整复验

适合继续：

- `npm run verify`
- 按 `docs/SMOKE_TEST_MATRIX.md` 做最小人工冒烟
- 按 `docs/FINAL_SUBMISSION_CHECKLIST.md` 做最终交付核对

### 第三优先级：再决定是否碰核心逻辑

只有在已经厘清当前未提交改动的来源、目标与边界后，再考虑：

- 搜索 / 筛选 / 排序规则调整
- 恢复逻辑优化
- 共享类型联动修改
- 主要页面结构层微调

## 10. 一句话原则

在比赛冲刺期，好的交接不是把所有背景一次性倾倒给下一位协作者，而是先用最短时间说明：**当前版本是否可讲、工程是否已验、工作区是否较脏、下一步该稳着做什么。**
