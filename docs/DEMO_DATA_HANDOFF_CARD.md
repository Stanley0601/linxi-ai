# Demo Data Handoff Card

用于在比赛冲刺、录屏准备或多人协作接手时，快速说明“当前浏览器里已经沉淀了哪些可直接用于演示的数据”，避免接手人误以为页面状态是随机的，或在错误时机执行重置。

## 适用场景

- 你刚跑出一条适合演示的聊天链路，准备交给别人接着录屏
- 你需要在答辩前快速同步“现在这台机器上还能直接展示什么”
- 你担心接手人不知道哪些本地状态值得保留、哪些可以重建
- 你希望在不改代码的前提下，降低演示数据断层带来的风险

---

## 1. 先确认这是一台“有状态”的浏览器

接手前，优先口头或文字同步以下四件事：

1. **最近继续演示的角色是谁**
2. **消息列表是否保存了最近搜索词 / 快捷视图**
3. **是否已有固定聊天、静音聊天、隐藏静音聊天**
4. **是否已经跑出可讲述的结局或关系阶段**

如果这四项里至少命中两项，就不要把当前浏览器当作“干净环境”。

---

## 2. 最短交接顺序（建议 30 秒内说清）

```text
先说最近继续演示的角色
  → 再说消息列表当前保留了什么搜索 / 视图偏好
  → 再说有没有固定 / 静音 / 隐藏聊天
  → 最后说是否已有结局、草稿、未读主动消息
```

推荐一句话模板：

> 当前浏览器已经沉淀了可直接演示的数据，先别重置；优先从最近会话继续，再按消息列表里保留的搜索词和快捷视图回到目标角色。

---

## 3. 建议重点同步的本地状态

### A. 会直接影响演示起手速度

优先级最高：

- 最近继续演示的角色
- 最近一次打开聊天的时间
- 最近一次消息列表搜索词
- 最近保存的快捷视图
- 当前是否已经有可继续会话

这些信息会直接决定：

- 进入应用后能否快速回到上次讲述节奏
- 是否需要重新搜索角色
- 是否需要重新手动切换筛选条件

### B. 会影响讲述逻辑但不一定影响起手

次优先级：

- 已固定聊天数量
- 已静音聊天数量
- 已隐藏静音聊天数量
- 聊天草稿数量
- 最近搜索标签数量
- 近期互动会话数量

这些信息更适合在接手人准备扩展讲述时使用，比如说明：

- 为什么某个角色会排在更前面
- 为什么某些会话默认不在列表首屏
- 为什么这次录屏能快速回到某个节点

### C. 会影响答辩收束表达

补充说明：

- 已达成的结局
- 当前关系阶段
- 兴趣画像与城市设置
- 最近一次结局摘要

这些内容更适合在答辩或复盘时快速补足“这不是静态 UI，而是有持续状态的体验链路”。

---

## 4. 交接时最容易踩的坑

### 坑 1：把“有状态浏览器”误当成“脏数据”

不要一看到页面有搜索词、固定聊天、最近会话，就立刻清空。

先判断：这些状态是不是正好能帮助更快进入演示。

### 坑 2：不知道列表排序为什么变了

如果接手人发现某些聊天排序和直觉不一致，先检查：

- 是否开启了最近互动优先
- 是否保留了最近打开聊天优先
- 是否存在固定聊天
- 是否正处在某个快捷视图下

### 坑 3：只交接角色，不交接入口

只说“接着演示林小宇”是不够的。

还要同步：

- 从“继续上次会话”入口进
- 或从消息列表搜索某个词进
- 或先切到某个快捷视图再进

### 坑 4：录屏前误触重置

如果当前浏览器已经具备：

- 可继续会话
- 最近搜索词
- 快捷视图偏好
- 已跑出的结局

那么录屏前默认不建议重置，除非当前状态已经明显偏离你要讲的故事。

---

## 5. 推荐的交接记录格式

```markdown
## YYYY-MM-DD HH:mm
- 分支：
- 当前浏览器状态：有状态 / 接近干净
- 最近继续演示角色：
- 最近搜索词：
- 当前快捷视图：
- 固定 / 静音 / 隐藏聊天：
- 草稿 / 未读 / 可继续会话：
- 最近结局摘要：
- 接手建议：
- 不建议动作：
```

---

## 6. 最短接手建议模板

### 模板 A：适合直接录屏

> 当前浏览器已保留最近会话与搜索偏好，建议先从“继续上次会话”进入，再根据消息列表中的搜索词或快捷视图补一段切换演示，不建议现在重置本地数据。

### 模板 B：适合答辩前同步

> 这台机器上已经有可讲述的本地状态，包括最近继续角色、消息列表搜索词和部分关系进度；如果答辩中断，可先回消息列表，再用已保留的入口恢复节奏。

### 模板 C：适合多人协作接手

> 当前不是干净环境，而是已沉淀演示数据的环境；接手时优先利用已有入口，不要先做“清空重来”的动作，除非明确要重跑另一条剧情。

---

## 7. 一句话原则

在比赛冲刺阶段，已经沉淀好的本地演示数据本身就是资产；交接的重点不是“这台机器改过什么”，而是“这台机器现在能直接讲什么，以及怎样最快讲出来”。
